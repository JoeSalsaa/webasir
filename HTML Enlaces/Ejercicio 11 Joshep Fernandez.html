Glosario de Conceptos de Sistemas Operativos

Tipos de usuarios de un Sistema Operativo

Usuario de órdenes / aplicaciones:
Usuario que interactúa con el sistema a través de comandos o aplicaciones.
Usuario programador
Usuario que desarrolla software y utiliza herramientas de programación del sistema.
Usuario diseñador / implementador:
Usuario que diseña e implementa componentes del sistema operativo.
Administrador del sistema:
Usuario encargado de la gestión y mantenimiento del sistema operativo.

Conceptos relacionados con el usuario de órdenes

Usuario:
Elemento (persona, máquina) identificable por el sistema.
Sesión:
Conjunto de acciones desarrolladas por el usuario desde que entra (login) hasta que sale (logout).
Programa:
Conjunto de instrucciones destinadas a resolver un problema.
Fichero o archivo:
Conjunto de datos relacionados almacenados en almacenamiento no perecedero.
Programa del sistema:
Acciones relacionadas con el SO.
Intérprete de órdenes:
Programa del sistema que recoge y manda ejecutar las órdenes del usuario.
